# .github

Výchozí komunitní soubory pro všechny veřejné repozitáře účtu **navik61**.

- `.github/FUNDING.yml` – tlačítko **Sponsor** (Ko-fi) u každého repozitáře, který nemá vlastní `FUNDING.yml`.

Repozitář musí zůstat veřejný a jmenovat se přesně `.github`, jinak GitHub výchozí soubory nepoužije.

---

Default community health files for all public repositories of **navik61**
(`.github/FUNDING.yml` → Ko-fi sponsor button for every repo without its own file).
